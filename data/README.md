# data/

Generated by `scripts/bootstrap/run_all.sh` from `data/_source/`. **Do not hand-edit**
the generated files — re-run the pipeline.

| File | What it is |
|---|---|
| `wp-pages.json` | Every WordPress page/post with its resolved path, status and raw content |
| `gsc-pages.json` | 91 URLs Google has indexed, with clicks/impressions/position |
| `gsc-queries.json` | 505 search queries with metrics |
| `services.json` | 3 service hubs + 16 children, derived from the WP page tree |
| `cities.json` | 36 cities: pattern, tier, existing pages, pages to build, GSC evidence, locality facts |
| `url-map.csv` | Every legacy URL and its disposition (preserve / restore / publish / redirect) |
| `preserved-urls.csv` | The 116 URLs that MUST return 200 — input to `npm run test:preservation` |
| `routes.json` | Flattened registry consumed by `lib/routes.ts` |
| `_source/` | The authoritative exports (WordPress XML, GSC xlsx, GA4 CSVs) |
| `_quarantine/` | GA exports belonging to a **different business** — see its README |

## Pipeline

```
extract_wp    WordPress XML + GSC xlsx  ->  wp-pages / gsc-pages / gsc-queries
build_url_map wp-pages + gsc-pages      ->  url-map.csv + preserved-urls.csv
build_cities  url-map + locality facts  ->  cities.json
annotate_geo  gsc-queries               ->  attaches query evidence to cities
reconcile     all of the above          ->  routes.json (fails if a 301 target won't exist)
```

## Current footprint

- **119** newly built pages
- **7** 301 redirects, all true duplicates
